# Landing Page Vinhomes Grand Park

Landing page quảng cáo bất động sản **Vinhomes Grand Park** (TP. Thủ Đức), xây dựng bằng HTML, CSS, JavaScript thuần và Bootstrap 5.3 qua CDN. Không dùng backend.

## Mục tiêu

- Giới thiệu nhanh dự án và thu thập thông tin khách hàng quan tâm (họ tên, số điện thoại).
- Hiển thị tốt trên điện thoại lẫn máy tính.
- Giao diện hiện đại, sang trọng, nhiều khoảng trắng.

## Danh sách tài liệu

| File | Nội dung |
|------|----------|
| `README.md` | Tổng quan dự án (file này) |
| `YEU-CAU-KY-THUAT.md` | Công nghệ, cấu trúc file, quy ước code |
| `GIAO-DIEN.md` | Màu sắc, bố cục, mô tả từng khu vực của trang |
| `NOI-DUNG.md` | Nội dung văn bản, nguyên tắc viết, hình ảnh |
| `PROMPT-ANTIGRAVITY.md` | Prompt hoàn chỉnh để dán vào Antigravity |

## Cấu trúc thư mục dự kiến

```
vinhomes-landing/
└── index.html      # Toàn bộ HTML + CSS + JS trong một file
```

## Cách chạy

Mở trực tiếp `index.html` bằng trình duyệt. Không cần cài đặt hay build.

## Lưu ý quan trọng

- Logo dùng dạng chữ, **không** dùng logo chính thức của Vinhomes khi chưa được phép.
- Ảnh trong bản đầu là placeholder, cần thay bằng ảnh có bản quyền hợp lệ.
- Không tự đưa giá bán, cam kết lợi nhuận hoặc số liệu pháp lý cụ thể vào nội dung.
